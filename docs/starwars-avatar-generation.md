# Star Wars avatars

Generated using the built-in image tool: Death Star, Tatooine twin sunset, and an Ewok village on Endor. Square illustrated compositions with central focal points for circular cropping, navy/teal backgrounds and warm highlights matching the existing collection. Assets are in `assets/avatars/starwars/`.

Initial Darth Vader and R2-D2 generation attempts were blocked; those assets are not included.
